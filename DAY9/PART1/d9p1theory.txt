Previously, we directly wrote database password inside code like this:password: "123456"
This is not safe because anyone can see your password if the code is shared.
So now we use a .env file.
>>>.env means environment file:It stores secret or changeable values like:
database password
database name
server port
JWT secret
API key
OpenAI key

[In real projects and hackathons, this is very important because later we will use API keys for:
OpenAI
OCR API
Speech-to-text API
Translation API
TTS API
So from today, we start using .env
]

Why edit package.json now?
Before, you may have run server like this:node server.js
That works.
But problem is: every time you change code, you must stop and restart server manually.

So now we use nodemon.
It auto-restarts server when code changes.
That is why we edit package.json.

Update only the scripts part:
"scripts": {
  "start": "node server.js",
  "dev": "nodemon server.js"
}
--------------------------------------------------
Now run server using:npm run dev
If you do not want to edit package.json, you can run:
npx nodemon server.js

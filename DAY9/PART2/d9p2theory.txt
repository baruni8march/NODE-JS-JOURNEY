In Express, async database code can fail.
Example: wrong SQL, wrong ID, database connection problem.
Previously we handled error inside every controller using try/catch.
But this repeats too much code.
So today we will create one common ****asyncHandler.****
It will catch async errors automatically.
Then one ***errorMiddleware*** will send error response.

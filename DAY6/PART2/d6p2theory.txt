We’ll use SQLite first because:
no heavy setup
no separate server needed
database is just one file
perfect for learning SQL with Node.js

SQLite stores data in a local .db file. Node can connect to that file and run SQL queries. We’ll use the sqlite3 npm package for this setup.

OTHER EXAMPLES OF db.run(`.....command....`);:
1.Create a table named todos if it does not already exist.
db.run(`
    CREATE TABLE IF NOT EXISTS todos (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        title TEXT NOT NULL,
        completed BOOLEAN DEFAULT 0
    )
`);


2.Add a new todo row.
db.run(`
    INSERT INTO todos (title, completed)
    VALUES ('Learn SQLite', 0)
`);

3.UPDATE/Mark todo with id 1 as completed.
db.run(`
    UPDATE todos
    SET completed = 1
    WHERE id = 1
`);

4.Delete todo with id 1.
db.run(`
    DELETE FROM todos
    WHERE id = 1
`);

#Database + SQL Intro

Until now your data was stored in:const todos = [];
Problem:If server restarts, all todos disappear.
So we need a database.

1. What is a database?
A database is a permanent storage system.
It stores data even after:
server stops
PC restarts
app crashes

Example:
users
todos
orders
products
messages

----------------------------------------------------------
There are 2 common types of database:
>>>>>>>>>>SQL & NoSQL<<<<<<<<<<

#SQL:
Data stored in tables.
Example:
PostgreSQL
MySQL
SQLite
[Looks like spreadsheet/table.]

#NoSQL:
Data stored like objects/documents.
Example:
MongoDB
[Looks like JSON.]

----------------------------------------------------

| id | title         | completed |
| -- | ------------- | --------- |

#### SQL CRUD Mapping ###

CRUD means:Create,Read,Update,Delete

{{{
You already did this in Express:
POST   /todos       → create todo
GET    /todos       → read todos
PUT    /todos/:id   → update todo
DELETE /todos/:id   → delete todo
}}}


Now SQL has commands for the same things:
1.SELECT * FROM todos;
:Show me all rows from todos table.lkOLP:[]

2.SELECT * FROM todos WHERE id = 1;
:Show me the todo whose id is 1.

3.INSERT INTO todos (title, completed)
VALUES ('Practice SQL', false);
:Add a new row into todos table.

4.UPDATE todos
SET completed = true
WHERE id = 1;
:Find todo with id 1 and change completed to true.

5.DELETE FROM todos
WHERE id = 1;
:Delete the todo whose id is 1.

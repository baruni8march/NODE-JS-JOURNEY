A Promise means:
"I promise I'll give result later."
Promise has 3 states:pending,fulfilled,rejected
5.Promise Example
const promise = new Promise((resolve, reject) => {
   let success = true;
   if (success) {
      resolve("Operation successful");
   } else {
      reject("Operation failed");
   }
});

promise
   .then((data) => {
      console.log(data);
   })
   .catch((err) => {
      console.log(err);
   });
===================================================
Code Explanation:
> new Promise() creates a Promise object
> by convention we usually pass:(resolve, reject)
> resolve means:success happened
> reject means:failure/error happened
> promises are asynchronous,so instead of try-catch,
older Promise syntax uses:.then() and .catch()
> if resolve("Success") runs,so .then((data)) executes,
where:data="Success"
> if reject("Failure") runs,then .catch((err)) executes,
where:err = "Failure"

7. Async/Await (MODERN BACKEND STYLE)
This is what real backend apps mostly use.
Async/await makes async code LOOK synchronous.

async function fetchData() {
   const result = await getData();
   console.log(result);
}
fetchData();

code:
>await getData():"Wait for promise to finish"
>await only works inside:async function

REAL BACKEND EXAMPLE:
const user = await User.findById(id);
const token = await bcrypt.hash(password);
Modern backend is FULL of async/await.

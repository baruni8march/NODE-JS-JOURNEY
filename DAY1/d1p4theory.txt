4. Read File
const fs = require("fs");
const data = fs.readFileSync("bio.txt", "utf8");
console.log(data);

Understanding:readFileSync
Meaning:read file synchronously
Why "utf8"?
Files are internally stored as binary.
utf8 converts file content into readable text.

Without utf8:<Buffer 48 65 6c 6c 6f>
weird output appears.

6. Sync vs Async Files
Synchronous:
fs.readFileSync()
>Node WAITS.

Asynchronous:
fs.readFile()
>>Node does NOT wait.

Example:
const fs = require("fs");
fs.readFile("bio.txt", "utf8", (err, data) => {
    console.log(data);
});
console.log("Finished");
Possible output:
Finished
I am learning Node.js

WHY?Because:
readFile is async
Node continues executing other code.
Exactly like:setTimeout
----------------------------------------------------------
7. Understanding Callback Here
This part:
(err, data) => {
   console.log(data);
}
is callback function.

Meaning:
"When file reading finishes,
run this code."
VERY IMPORTANT
Most Node.js backend work is:
asynchronous
Because:
databases are slow
APIs are slow
uploads are slow

Async prevents server blocking.

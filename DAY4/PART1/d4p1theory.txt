#ROUTE PARAM
What is a route param?
A route param is a value inside the URL.
Example:
GET /todos/2
Here:
2 = todo id
like in express:app.get("/todos/:id", (req, res) => {
    const id = req.params.id;
});

>>>req.params.id gets the value from URL.
